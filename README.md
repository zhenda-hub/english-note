# english-note

面向英语学习者的个人学习笔记站，基于 [MkDocs Material](https://squidfunk.github.io/mkdocs-material/)，按**学习路径**组织内容，方便自己也方便他人循序渐进地学习。

## 内容结构（docs/）

| 板块 | 路径 | 说明 |
| --- | --- | --- |
| 首页 / 学习路线 | `docs/index.md` | 五步学习路径：认识英语 → 语音词汇 → 连词成句 → 主题场景 → 资源 |
| 认识英语 | `docs/intro/` | 英语的特点与历史、怎么学（含“把认识变成会用”造句方法） |
| 语音与词汇 | `docs/words/` | 发音（音标 / 发音核心 / 单词重音）+ 词汇（构词 / 易混词 / 数字时间 / 程度可能性） |
| 连词成句 · 语法 | `docs/grammar/` | 词法 → 句法 → 语气 三层递进（词性、句型、从句、时态、疑问、条件、虚拟…） |
| 主题场景 | `docs/topics/` | 餐厅 / 就医 / 职场 / 校园 / 购物 / 影视 / 社交等场景词句 |
| 资源宝库 | `docs/tools.md` | 词典、翻译、学习 App、影视剧单 |

## 本地开发

```bash
uv run mkdocs serve   # 本地预览 http://127.0.0.1:8000
uv run mkdocs build   # 构建到 site/
```

## 约定

- **命名即内容**：文件名与导航标签必须能看出页面内容。
- **内容归口**：系统性语法规则收进 `grammar/`；场景页只保留“用得起来”的词句，必要时链接到语法页。
- 页面用 `#` H1 作标题，与导航标签一致；未写完的段落标注 `📝 待补充`。
