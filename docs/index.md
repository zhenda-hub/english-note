这里是我沉淀英语学习点滴的小站。所有笔记按**学习路径**组织，跟着顺序读就能循序渐进；也可以把它当词典/手册随时查。

## 🗺️ 建议学习路线

| 阶段 | 看哪里 | 收获 |
| :--- | :--- | :--- |
| ① 认识英语 | 「认识英语」 | 理解英语为什么“不规则”，调整心态，学会怎么学 |
| ② 语音与词汇 | 「语音与词汇」 | 会查音标、懂发音重点；用词根词缀、分类词汇积累单词 |
| ③ 连词成句 · 语法 | 「连词成句 · 语法」 | 从词性 → 基本句型 → 三大从句 → 时态 → 疑问/条件/虚拟，把词变成句子的完整主线 |
| ④ 主题场景 | 「主题场景」 | 在餐厅、医院、职场、校园等场景里直接套用的词句 |
| ⑤ 资源宝库 | 「资源宝库」 | 词典、翻译、学习 App、影视材料 |

> 语法区按三层递进：**词法**（词的性质与变化）→ **句法**（把词拼成句子）→ **语气**（假设与态度）。
