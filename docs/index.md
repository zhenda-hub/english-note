- 页面中带 📝 待补充 的段落是还没写满的占位，会随学习持续更新。
- 英语学习没有捷径，愿我们都能在日复一日的积累中，遇见更好的自己～

## 🤝 一起维护：欢迎来改

这份笔记一直在长，也一定会出错。**发现错译、想到更好的例句、看到漏掉的用法，直接改就行**，不用先问我。

三种参与方式，从轻到重：

1. **看到问题直接改** —— 每页标题右侧的 ✏️ 铅笔按钮，点进去就是 GitHub 网页编辑器。有仓库权限的改完直接提交；没有的话 GitHub 会自动帮你 fork 一份，点 **Propose changes** 就能开 PR，我看到就合。
2. **只提问题，不动手** —— 到 [Issues](https://github.com/zhenda-hub/english-note/issues) 说一声：哪一页、哪一句、为什么不对。
3. **零散句子先丢收件箱** —— 还没想好归哪类的句子，加进 [句子收件箱](todo.md)，我定期分发到对应页面。

两条约定：

- 只改 `docs/` 里的内容；`site/` 是自动构建的产物，不要手改。
- 加句子尽量带上中文释义和语境（什么时候说、对谁说），比单给一句英文有用得多。
