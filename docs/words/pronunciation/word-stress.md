# 单词重音（Word Stress）

## 以 -ion 结尾的单词

重音落在**倒数第二个音节**上：

> Words that end in -ion always have their stress on the next-to-last syllable.

- decision /dɪˈsɪʒən/ → de-**CI**-sion
- connection /kəˈnekʃən/ → con-**NEC**-tion
- communication /kəˌmjuːnɪˈkeɪʃən/ → …ni-**CA**-tion

📝 待补充：-tion / -sion / -ity / -ic 等常见后缀的重音规律；句子层面的节奏与重音见 [发音核心](connected-speech.md)。
