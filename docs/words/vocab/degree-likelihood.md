# 程度 · 可能性 · 频率

## 可能性（强 → 弱）

- absolutely / definitely 绝对、肯定
- probably 很可能
- maybe 也许
- unlikely 不太可能

## 程度分级（问题 / 情况严重度）

small < serious < severe

- It's a small problem, and there's no need for concern.（小问题，不用担心。）
- It's looking like a serious issue.（看起来是个严重的问题。）
- We have a severe problem.（我们遇到了非常严重的问题。）

## 程度修饰语

- nowhere near … = 远不及、差得很远 → The new version is nowhere near as good as the old one.

## 疲劳同义词的强度递进

overworked（过度劳累，偏工作量大）< exhausted（精疲力尽，体力／精力耗尽）< fatigued（疲惫不堪，偏正式，也用于医学上的疲劳）

- I'm overworked and exhausted after working 50 hours this week. 这周上了 50 小时班，我又累又疲于奔命。

📝 待补充：频率副词（always / usually / sometimes / never 等）。
