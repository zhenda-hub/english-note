# 动词与时态

## 动词分类

### 实义动词

表示“做什么 / 发生什么”：

run, eat, think, work

### 系动词（连接用）

be, seem, look, become

### 助动词

作用：

- 构成时态
- 构成否定
- 构成疑问

be / do / have


### 情态动词（态度表达）

- can / could（能力、许可、可能性）
- may / might（许可、可能性）
- must（必须、强烈推测）
- shall / should（应当、建议）
- will / would（将来、礼貌请求）
- ought to（应当）

特点：
- 后接动词原形（无 to）
- 无时态变化（第三人称不变）
- 否定加 not（cannot, shouldn't）

示例：
- Can you help me?（你能帮我吗？）
- You should study harder.（你应该更努力学习。）
- It might rain.（可能要下雨。）

## 动词语法

### 被动语法

be + 过去分词

need -> be needed


### 第三人称单数

have -> has

只影响一般现在时，其他时态不用纠结。

### 动词的时态


过去分词: 动词 + ed

| 用法       | 结构                | 例子                      |
| ---------- | ------------------- | ------------------------- |
| 现在完成时 | have/has + 过去分词 | I have **eaten**          |
| 被动语态   | be + 过去分词       | The homework was **done** |
| 作形容词   | 过去分词修饰名词    | a **broken** window       |




实际上英语真正常用的时态只有：

现在 / 过去 / 将来 × 简单 + 进行 + 完成 = 9 种常用。

简单时： I eat / I ate / I will eat
进行时： I am eating / I was eating / I will be eating
完成时： I have eaten / I had eaten / I will have eaten
这 9 个覆盖 99% 的实际使用场景。





| ⏰ 时间             | 🌱 核心时态（90% 用于日常）                         | 🌿 常用补充（10%）                  | 🪶 很少使用（可略）                         |
| :----------------- | :--------------------------------------------------- | :----------------------------------- | :------------------------------------------- |
| **现在 (Present)** | ✅ 一般现在时 → I eat.                               |                                      | ⚪ 现在完成进行时 → I have been eating.      |
|                    | ✅ 现在进行时(be doing)[动作正在进行] → I am eating. |                                      |                                              |
|                    | ✅ 现在完成时(have done) → I have eaten.             |                                      |                                              |
| **过去 (Past)**    | ✅ 一般过去时 → I ate.                               | ☑️ 过去完成时 → I had eaten.       | ⚪ 过去完成进行时 → I had been eating.       |
|                    |                                                      | ☑️ 过去进行时 → I was eating.      |                                              |
| **将来 (Future)**  | ✅ 一般将来时 → I will eat.                          | ☑️ 将来进行时 → I will be eating.  | ⚪ 将来完成进行时 → I will have been eating. |
|                    |                                                      | ☑️ 将来完成时 → I will have eaten. |                                              |


have done for
have done since

过去现在的时间描述:

- The party will begin in 10 minutes.
- The party started 10 minutes ago.

#### 现在完成时小补充

- **have been to** = “去过（已回来）” → I've been to the doctor's.（对比：have gone to = 去了还没回来）
- **have done / have had** = 已经完成 / 经历过 → I've done my homework. I've had lunch.
- **have been + 形容词** = 从过去一直持续到现在的状态 → I've been busy all week.

#### 现在完成进行时：have/has been doing

表示“从过去一直进行到现在，可能仍在继续”：

- I've been waiting here for an hour.
- I've been feeling tired recently.

> 对比：**be doing**（现在进行，动作正在进行）↔ **have been doing**（现在完成进行，从过去持续到现在）。

#### 过去将来：was / were going to

表示“当时打算要做的事”，常接 **but + 过去时** 说明转折或没做成：

- They were going to separate, but they fell in love again.




### 非谓语动词

当动词不是句子的**主要谓语**

| 形式  | 名称              | 示例     | 用途        |
| ----- | ----------------- | -------- | ----------- |
| to do | 不定式            | to learn | 目的 / 计划 |
| doing | 动名词 / 现在分词 | learning | 动作 / 过程 |
| done  | 过去分词          | learned  | 被动 / 完成 |


Learning English is important.

真正的谓语是 is， 而不是 learning。


### 短语动词（Phrasal Verbs）
