# 名词与数量词

## 可数名词（countable nouns）的数量修饰

- **a few**（几个）→ a few books
- **many**（许多）→ many books

## 不可数名词（uncountable nouns）的数量修饰

- **a little**（一点点）→ a little water
- **much**（许多）→ much time（多用于否定句和疑问句）
- **a lot of**（许多）→ 可数、不可数名词都可以用

## both / neither：谈论“两者”

- **both** 肯定两者：both packages are …（两个包裹都…）
- **neither** 否定两者：neither package is …（两个包裹都不…；neither 作主语时谓语用单数）

> 这两个词常出现在“售后服务对比两个套餐”之类的对话里。
