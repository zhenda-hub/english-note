# 疑问句：反义疑问与间接问句

## 间接问句 / 疑问词从句：语序改回“主语 + 动词”

把问句放进从句里（或转述别人的问题时），**语序不再倒装**，改成：疑问词 + 主语 + 动词；转述的动词常用过去时（asked / wondered），从句里的时态视情况跟着回移。

直接问 → 转述：

- How is the team doing?
  → Cody asked how the team is doing.（Cody 问团队现在进展如何）
- When are we going to get a new computer system?
  → John asked when we were going to get a new computer system.（are → were）

“我不知道 / 想知道 + 疑问词从句”也用同样的语序（陈述语序，不倒装）：

- I don't know where the school is.
- I wondered how good the instructors were.

## 反义疑问句（tag questions）

tag questions 反义疑问句 = 陈述句 + 简短问尾，用来向对方求证或确认。
