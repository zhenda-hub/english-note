# 基本句型：从 5 种骨架开始

英语的句子大部分是固定句型，学会模板，就能套用新词。

- 主语 + 谓语 (S + V) → He runs.
- 主语 + 谓语 + 宾语 (S + V + O) → She likes music.
- 主语 + 系动词 + 表语 (S + be + Adj/N) → The book is interesting.
- 主语 + 谓语 + 间宾 + 直宾 (S + V + IO + DO) → He gave me a gift.
- 主语 + 谓语 + 宾语 + 宾补 (S + V + O + OC) → They elected him president.

> 骨架搭好后，句子变长主要靠两件事：[三大从句](clauses.md) 扩展，以及 [动词与时态](../01-word-classes/verbs.md) 带来的时态、语态变化。
