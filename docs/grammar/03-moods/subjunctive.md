# 虚拟语气

that + 主语 + 动词原形(而不是陈述句第三人称)

| 动词        | 句子                                     |
| --------- | -------------------------------------- |
| suggest   | I suggest that he **go**.              |
| recommend | I recommend that she **apply**.        |
| propose   | I propose that we **change** the plan. |
| insist    | She insists that he **leave**.         |
| demand    | They demanded that he **pay**.         |

> 想表达“如果…就会… / 与事实相反的假设”，见 [条件句与假设](conditionals.md)。
