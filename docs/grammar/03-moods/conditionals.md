# 条件句与假设（Conditionals）

## 真实条件句：if + 一般现在时，主句 will

谈论“很可能发生 / 真实”的条件：

- If I don't work hard, I'll lose my job.
- = Unless I work hard, I'll lose my job.（unless = if not）

## 假设条件句：与现在事实相反

**If + 过去式，主语 + would + 动词原形**

- If I had more money, I would travel more.
- If I had more time, I would learn English.
- What would you do if you had more free time?

> 你把它记成一个固定公式：If + 过去式，主语 + would + 动词原形
