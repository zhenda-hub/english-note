## 学习方法

### 语言习得=“输入足够+输出及时+反馈闭环”

- **输入**：听、读（吸收语言素材，积累表达）；
- **输出**：说、写（主动运用，检验掌握程度）；
- **反馈**：纠正错误（比如发音问题、语法漏洞）；
- 误区：只背单词/学语法（单一输入）、不敢开口/不写句子（缺乏输出），都会导致“学用脱节”。


语言学习的真相

| 真相            | 说明                                  | 实践意义                 |
| :-------------- | :------------------------------------ | :----------------------- |
| 1. 输入优于输出 | 听懂比会说更重要，读懂比会写更重要    | 先大量输入，输出自然产生 |
| 2. 可理解性输入 | 材料难度应为「i+1」（略高于当前水平） | 选择85%能懂的材料学习    |
| 3. 遗忘是正常的 | 艾宾浩斯曲线：1天后遗忘66%            | 间隔复习是关键           |


### 水平匹配原则：“跳一跳够得着”的难度最有效
- 过易（如用小学教材学四六级）：浪费时间，无进步；
- 过难（如初学者直接看《经济学人》）：挫败感强，容易放弃；
- 标准：阅读时70%-80%内容能理解，听力时能抓住核心大意，剩下的通过上下文或查资料补充。


### 造句：把“认识”变成“会用”

很多人词汇量比造句能力强：认识很多单词，用的时候却“卡壳”——问题在于只完成了“知道”，没完成“会用”。

为什么会这样？

- 输入碎片化：单词记住了，却没和句子、语境绑定；
- 缺少输出练习：很少主动造句，大脑里没有“使用的路径”；
- 过于依赖熟词：说写时习惯用那 1000 个“安全单词”，不敢尝试新词。

怎么练？**词 → 短语 → 句子**：

1. 不要孤立记单词，把它记成“搭配”；
2. 例如 influence（影响）→ 记短语 have an influence on … → 造句 Social media has a strong influence on teenagers.；
3. 句子的骨架从哪来？见 [基本句型](../grammar/02-sentences/patterns.md)——学会模板，用新词去套。

### 常见误区避免

- 别用母语（旧思维）逐句翻译
- 别只学语法不实践。
- 别怕犯错：native speakers更欣赏你努力沟通的样子。
- 别一次性学太多：每天30-60分钟，坚持胜过强度。

### 多语言学习经验

如果你学过一门外语，再学另一门会更快（迁移效应）。

## 结语

> 语言不是学会的，是慢慢长出来的。
