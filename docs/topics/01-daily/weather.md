# 天气（Weather）

## 寒暄问句

天气是最好用的开场话题，问一句就能自然聊起来。

- What's the weather like today? 今天天气怎么样？
- What's the weather like over there? 你那边天气怎么样？
- Nice weather today, isn't it? 今天天气不错，是吧？（典型的英式寒暄）

## 潮湿与干燥

- It's humid today. 今天很潮（闷）。
- It's really dry here. 这里真的很干。
- hot and humid 又热又潮
- humidity 湿度（名词）

## 常见天气词

- sunny 晴天 / cloudy 多云 / overcast 阴天
- rainy 下雨的 / a light rain 小雨 / pour 下大雨（It's pouring. 正在下大雨）
- windy 有风的 / freezing 冷得要命 / chilly 有点凉
- a heat wave 热浪 / a cold snap 寒潮
